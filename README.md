Este es un juego de Tic Tac Toe (Tres en Línea) desarrollado como parte de un reto técnico.

El juego permite jugar de dos formas:

- Jugador vs CPU 
- Jugador vs Jugador 

También cuenta con un sistema de puntuación y permite guardar y reanudar una partida.

*Cómo ejecutar el juego

No es necesario instalar nada para ejecutar el proyecto.

Solo debes:

1. Descargar o copiar la carpeta del proyecto.
2. Abrir la carpeta en Visual Studio Code o directamente en el explorador de archivos.
3. Abrir el archivo index.html en un navegador.
4. ¡Listo! Ya puedes jugar 

También puedes utilizar la extensión Live Server de Visual Studio Code para ejecutar el proyecto.

*Tecnologías utilizadas

El proyecto fue realizado utilizando:

- HTML5: para crear la estructura del juego.
- CSS3: para el diseño, colores, animaciones y adaptación a diferentes pantallas.
- JavaScript: para toda la lógica del juego.
- LocalStorage: para guardar la partida y la puntuación.

No se utilizaron frameworks ni librerías externas.

*Estructura del proyecto

*index.html

Es la estructura principal del juego. Aquí están las diferentes pantallas, botones, nombres de los jugadores, tablero, marcador y ventanas de resultados.

*style.css

Contiene el diseño del juego. Aquí se encuentran los colores, tamaños, botones, tablero, animaciones y estilos para que el juego se adapte a diferentes dispositivos.

*script.js

Contiene toda la lógica del juego. Se encarga de los turnos, movimientos, ganadores, empates, puntuación, modo CPU, reinicio y guardado de la partida.

*assets

Esta carpeta contiene los recursos gráficos utilizados en el juego, como el fondo y las imágenes que aparecen cuando hay una victoria, derrota o empate.

*README.md

Contiene la información del proyecto, cómo ejecutarlo, las tecnologías utilizadas y la estructura de los archivos.

Características

- Juego de Tic Tac Toe para 2 jugadores.
- Modalidad jugador vs CPU.
- Modalidad jugador vs jugador.
- Sistema de puntuación.
- Opción para reanudar la partida.
- Diseño adaptable a Desktop, Tablet y Smartphone.
- Efectos de sonido.
- Mensajes de victoria, derrota y empate.
